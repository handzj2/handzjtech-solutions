# ACCESSIBILITY CONTRACT

## Required (Increment 1)
- Semantic HTML throughout.
- Skip link to main content.
- Full keyboard navigation, including mobile navigation disclosure.
- Visible focus states on all interactive elements.
- Accessible labels (aria-label / aria-expanded / aria-controls where relevant).
- Sufficient color contrast for text and interactive elements.
- Meaningful alt text (empty alt for decorative images only — none invented in Increment 1).
- Logical heading hierarchy, one H1 per page.
- Accessible forms (deferred — no form processing built yet, but markup should still follow accessible patterns where a form shell exists).
- `prefers-reduced-motion` support.
- Touch targets ~44px minimum.
